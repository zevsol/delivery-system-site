已验证的流程从本地源码检出开始，并使用兼容的 MCP Host。不同 Host 的配置界面会有所不同。

已验证边界

这是源码检出指南，不是通用一键安装器。公开 main 的新检出版本可能尚未包含近期 DS Lite Skill 的 Markdown 展示改动。

01 / 前置条件

开始之前

需要 Python 3.10+、Git、Delivery System 源码，以及支持本地 stdio 服务的 MCP Host。概念预览流程不需要 GitHub 写入凭据。

02 / 安装

创建隔离环境

克隆产品源码仓库，并根据仓库锁定文件安装运行时依赖。

PowerShell
git clone https://github.com/zevsol/delivery-system.git
cd delivery-system
python -m venv .venv
.\.venv\Scripts\python.exe -m pip --isolated install --no-user --no-cache-dir --index-url https://pypi.org/simple --no-require-hashes -r pylock.toml
03 / MCP 服务

配置本地服务

使用虚拟环境中的 Python 启动 stdio 服务模块，并为预览状态设置专用本地工作区。各 Host 的配置格式不同。

MCP server · semantic example
<repo>\.venv\Scripts\python.exe -B -m mcp_server.server --workspace-root <absolute-workspace-path>

各 Host 配置格式不同，请按 Host 文档填写命令、参数和工作目录。

04 / Skill

加载规划 Skill

通过 Host 自身的 Skill 机制加载规划 Skill 文件夹。不同 Host 不一定会自动发现仓库中的 Skill。

skills/plan-github-work-items ↗ 通过 Host 的 Skill 机制加载此目录。公开 main 可能尚未包含近期 Markdown 展示改动。

05 / 第一个需求

描述目标结果

写清目标、范围、约束和非目标。检查返回的预览后，再决定是否复制 Issue 草稿。
