03 GUIDING PRINCIPLES
01 /

Intent before action

The plan should be understandable and reviewable before any remote change happens.

02 /

Explicit human decisions

Approval is not inferred from a model response or a successful preview.

03 /

Evidence over assertions

Preview, revision, audit evidence, and execution results are separate things.

04 /

Stop on ambiguity

Unknown write outcomes should not become blind automatic retries.
