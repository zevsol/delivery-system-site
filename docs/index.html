LOCAL SETUP · SOURCE CHECKOUT

Run the preview
in your own Host.

The verified workflow runs from a local source checkout with a compatible MCP Host. Exact configuration screens differ by Host.

Verified boundary

This is a source-checkout guide, not a universal installer. A fresh checkout of public main may not include the recent DS Lite Skill Markdown presentation changes.

01 / PREREQUISITES

Before you start

Python 3.10+, Git, the Delivery System source checkout, and an MCP Host that supports a local stdio server. The conceptual Preview flow does not need GitHub write credentials.

02 / INSTALL

Create an isolated environment

Clone the product repository and install its pinned runtime dependencies from its lock file.

PowerShell
git clone https://github.com/zevsol/delivery-system.git
cd delivery-system
python -m venv .venv
.\.venv\Scripts\python.exe -m pip --isolated install --no-user --no-cache-dir --index-url https://pypi.org/simple --no-require-hashes -r pylock.toml
03 / MCP SERVER

Configure the local server

Use the virtual-environment Python executable, launch the stdio server module, and set a dedicated local workspace root for Preview state. Host configuration syntax varies.

MCP server · semantic example
<repo>\.venv\Scripts\python.exe -B -m mcp_server.server --workspace-root <absolute-workspace-path>

Host config syntax varies; use your Host documentation for command, arguments, and working directory.

04 / SKILL

Load the planning Skill

Expose the planning Skill folder using the Host’s Skill mechanism. Hosts do not all discover repository Skills automatically.

skills/plan-github-work-items ↗ Load this folder through your Host Skill mechanism. The public main branch may not yet include recent Markdown presentation changes.
